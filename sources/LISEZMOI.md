# Dépôt des sources

Déposez ici le document original à mettre en page (PDF, Word, images…),
par glisser-déposer depuis l'interface web GitHub :

1. Ouvrir <https://github.com/nedjahchafik/nedjahchafik> ;
2. Entrer dans ce dossier `sources/` puis cliquer sur **Add file → Upload files** ;
3. Glisser le fichier (ex. `Concept Hana Format A4.pdf`), puis **Commit changes**
   (branche au choix : `main` ou `arena/01a07cff-nedjahchafik`) ;
4. Prévenir dans le chat Arena : le fichier est alors analysé et recomposé
   en présentation A4 officielle.

Le contenu de ce dossier n'est pas publié dans les livrables ; il sert
uniquement de source d'analyse.
